One original line: an alien tourist's review of planet Earth.

> Earth: four stars. The locals built a box that washes their dishes, then stand beside it arguing about how to load it.

118 characters, one line, plain text. The program copies `entry.txt` to the output directory.

## How the line meets the judge's criteria, in order

1. **Alien tourist's review of Earth:** opens "Earth: four stars" — a review verdict on the planet, and "the locals" marks the writer as a visitor looking in from outside.
2. **Funny from the alien's angle:** the laugh comes from the visitor watching ordinary Earth life — humans automated the chore, then kept the chore as an argument.
3. **Original:** not traffic, gravity, money or weather — the dishwasher-loading argument is a specific, everyday detail few entrants would reach for.
4. **Sounds like a real tourist review:** a star verdict up front, a single observation, a closing remark, all in one line.
5. **Tight:** 118 of 200 characters, one joke only, and the punch ("arguing about how to load it") lands on the last word.
